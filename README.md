## 功能简介

### 课表

- 教务系统一键导入，也支持手动添加
- 多周次浏览，多套配色方案与自定义背景
- 课表方案可导出、可导入，换手机不丢课表
- 桌面小组件同步今日课程与「下一节课」
- 上课前自动提醒

### 学业

- **我的学业**：培养方案全景 —— 计划学分 / 已修 / 在读 / 未修 / 未过一目了然，GPA 与学分进度直接对上教务
- 成绩查询、考试查询、教材查询，按学期归档，本地缓存
- 未过课程单独标红，选课状态与教务口径一致

### 生活

- 一卡通余额与消费明细
- 宿舍电费查询

### 待办

- 到点提醒，支持每天 / 每周重复与三级优先级
- 精确闹钟兜底：清掉后台、息屏也能响
- 课程待办自动同步，删掉之后不会被重新加回来
- 待办日历：月视图按待办数量显示深浅

### 资源中心

- 教材中心按课程自动去重
- 教材 PDF、历年试卷与配套答案
- 上传需审核，可署名贡献者
- App 内直接下载与阅读，不跳出

### 个性化

- 深色模式、主题色、背景色、字体大小、圆角、动效强度、振动反馈
- 首页板块自由组合，底部导航项可自定义隐藏与排序
- 校历、校园地图内置，离线可用

## 安装

下载 APK 直接安装（arm64，Android 8.0 及以上）。

## 构建

环境：Flutter **3.29.3** · JDK 21 · Android SDK 35

```bash
flutter pub get
flutter run
flutter test
flutter build apk --release --target-platform android-arm64
```

推送代码后 GitHub Actions 会自动跑静态检查与单元测试。

## 开发

提交前请确保这两条都是零问题：

```bash
flutter analyze lib test
flutter test
```

`flutter analyze` 默认把 info 也算失败，所以「有 150 条 info」等于 CI 红。本地看到 `No issues found!` 才算过。

## 登录

使用学校统一认证账号（学号 + 密码）登录。账号密码保存在手机本地安全存储，退出登录时一并清除。

所有数据只存在手机本地，客户端直连学校系统，不经过任何第三方服务器。
