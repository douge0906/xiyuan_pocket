## 功能简介

### 课表

- 教务系统一键导入，也支持手动添加
- 多周次浏览，多套配色方案与自定义背景
- 课表方案可导出、可导入，换手机不丢课表
- 桌面小组件同步今日课程与「下一节课」
- 上课前自动提醒

### 学业

- **我的学业**：培养方案全景 —— 计划学分 / 已修 / 在读 / 未修 / 未过一目了然，GPA 与学分进度直接对上教务
- 成绩查询、考试查询、教材查询，按学期归档，本地缓存
- 未过课程单独标红，选课状态与教务口径一致
- **空教室查询**：按周次、星期、节次、楼号查没课的教室，带座位数

### 生活

- 一卡通余额与消费明细
- 宿舍电费查询
- **校园地图**：可旋转的 3D 校园模型，按楼名搜索、按用途分类；离线可用，不申请定位权限

### 待办

- 到点提醒，支持每天 / 每周重复与三级优先级
- 精确闹钟兜底：清掉后台、息屏也能响
- 课程待办自动同步，删掉之后不会被重新加回来
- 待办日历：月视图按待办数量显示深浅
- 倒数日：桌面小组件可选格子显示

### 资源中心

- 教材中心按课程自动去重
- 教材 PDF、历年试卷与配套答案；`.docx` 在线看正文，不用先下载
- 上传需审核，可署名贡献者；每份资源可报问题
- App 内直接下载与阅读，不跳出；「我的下载」统一管理本机已存文件
- 邀请同学可加每日下载额度

### 消息

- 公告与校本资讯一起看，一个容器 + 多个来源
- 首次安装就有内置快照，不用干等联网
- 本地缓存离线可看

### 个性化

- 深色模式、主题色、背景色、字体、字号、圆角、振动强度
- 首页板块自由组合，底部导航项可自定义隐藏与排序
- 校历、学生手册、校园地图内置，离线可用
- 语音输入

## 构建

环境：Flutter **3.29.3** · Dart 3.7.2 · JDK 21 · Android SDK 35

```bash
flutter pub get
flutter run
flutter test
flutter build apk --release --target-platform android-arm64
```

正式发版**不要用上面的命令手打**：打出来的包不带版本号命名、不做 AAPT 校验，
也落不到统一的交付目录。发版走 `xiyuan_ops/build_pocket.py`。

## 登录与数据

用学校统一认证账号（学号 + 密码）登录。账号密码保存在手机本地安全存储，
退出登录时一并清除；登录请求由手机直接发往学校系统，**密码不会离开这台手机**。

绝大部分数据是**手机自己去学校网站抓的**：课表、成绩、考试、空教室、教材、
一卡通余额、电费、教务公告。这些内容不经过任何第三方服务器，也不上传。

只有 5 类事情需要联网到开发者自建的服务端：版本检查与更新、公告、校历、
试卷题库、资源中心。这类请求会带上一个由设备信息单向派生、无法还原出
原始设备号的安装标识，以及平台与 App 版本；登录后另带一个由学号在本地
算出、服务端无法反推学号的伪名，和你自愿填写的显示名。

**不会上传**：统一认证密码、Cookie、课表 / 成绩 / 考试 / 教材 / 余额内容、
通讯录、短信、位置、相册、麦克风、摄像头数据。

课表、成绩等数据保存在手机本地（`SharedPreferences` / secure storage），
换机或清除数据后需重新登录拉取。
