# 掌上锡院隐私政策

**版本：v1.1　生效日期：2026-11-20**

掌上锡院（以下简称“本应用”）是由个人开发者维护的校园工具。本政策说明 Android 客户端如何处理你的信息，以及你享有的权利。使用本应用前，请阅读并理解本政策。

---

## 1. 适用范围

本政策适用于 Android 客户端。学校统一认证、教务、一卡通、宿舍等由学校或其服务商提供的系统，适用其各自的隐私规则，不属于本政策范围。

## 2. 我们处理哪些信息

### 2.1 只保存在你手机上的信息

- **统一认证账号与密码**：仅保存在本机安全存储，用于代你向学校系统发起登录；退出登录时清除。密码不会发送到开发者控制端。
- **课表、成绩、考试、学业、教材、一卡通余额等查询结果**：保存在本机，用于离线查看和界面展示；不会上传到开发者控制端。

### 2.2 登录开发者控制端时发送的信息

为了提供版本检查、公告、校历、资源库、设备登记和账号额度，App 会连接开发者自建控制端 `https://con.wxxydouge.icu`（位于中国境内），并发送：

| 信息 | 内容与来源 | 用途 |
| --- | --- | --- |
| 学号伪名 | 由学号在手机本地计算的 SHA-256 伪名（`xiyuan-control\|student\|学号`） | 账号识别、额度与邀请关系 |
| 显示名 | 你主动填写的昵称，可为空 | 界面展示 |
| 设备安装标识 | 由 `ANDROID_ID` 单向派生的标识（`xiyuan-` + SHA-256 前 16 字节） | 设备登记、防滥用、按设备限额 |
| 设备公钥与设备序列号 | App 首次启动时在本机生成的 P-256 密钥对，公钥上传，私钥不出设备 | 校验登录/请求签名，防止冒充 |
| 平台与 App 版本 | `android`、版本号 | 兼容性判断与更新提示 |
| 网络与访问日志 | IP 地址、访问时间、请求路径、响应状态 | 安全防护、故障排查、限额统计 |

**关于原始学号：** 使用 v1 断言的历史客户端会在登录断言中附带原始学号，供服务端重新计算伪名并校验签名。服务端只用它做这次校验，**从不保存明文**，也不会写入日志。使用 v2 断言的新版客户端只发送本地伪名，原始学号不再离开设备。

**关于账号标识：** 服务端不会直接保存上述 64 位伪名，而是保存 `HMAC-SHA256(服务端密钥, 伪名)` 及其 8 位展示标签。由于服务端密钥不对外公开，即使数据库泄漏，也无法通过枚举学号反推出账号。

**关于设备标识：** 本应用不使用 IMEI、MEID、MAC 地址、手机号或通讯录作为设备标识。`ANDROID_ID` 由系统按“应用签名 + 用户 + 设备”生成，卸载重装通常不变，恢复出厂设置或更换设备后会变化。

### 2.3 我们不收集的信息

Android 客户端**不会**向开发者控制端发送：

- 统一认证密码；
- 学校系统 Cookie、登录票据；
- 课表/成绩/考试/教材/一卡通余额等查询内容；
- 通讯录、短信、通话记录、精确位置、相册、麦克风、摄像头、剪贴板内容、已安装应用列表。

本应用不集成广告 SDK，不做用户画像，不出售或出租个人信息。

## 3. 存储位置与保留期限

- 控制端服务器与数据库位于中国境内。
- 账号记录（伪名 HMAC、显示名、额度、邀请关系、会话记录）在你使用账号期间保留；申请注销后删除或匿名化。
- 服务器访问日志保留不超过 30 天；聚合后的匿名统计（不含账号、设备标识、IP）可长期保留。
- 本机数据随 App 卸载删除；系统备份是否保留由你的手机系统设置决定。

## 4. 第三方服务

- **腾讯云 COS / EdgeOne**：资源中心的学习资料存储在中国境内的腾讯云 COS，并通过 EdgeOne 加速分发。该过程只涉及文件本身和你下载文件所需的网络请求，不涉及账号伪名或设备标识。
- **Let's Encrypt**：为控制端提供 TLS 证书。
- 除上述基础设施和法律法规要求外，开发者不会向第三方提供你的个人信息。

学校系统由学校或其服务商独立运营。登录与查询由手机直接发往学校系统，不经过开发者控制端。

## 5. 传输与安全

- 控制端全站使用 HTTPS（TLS 1.2/1.3）。
- 登录使用一次性挑战 + 设备私钥签名，重放或篡改的断言会被拒绝。
- 服务端按最小必要原则保存数据，账号键使用独立密钥做 HMAC，数据库不保存可枚举的学号哈希。
- 校内教务、宿舍等由学校提供的接口中，部分仍使用 HTTP，且仅能在校园网访问；这些请求不经过开发者控制端。

任何系统都无法保证绝对安全。如发现异常，请通过下方渠道联系开发者。

## 6. 你的权利

你可以：

- 在 App 内查看和修改显示名；
- 通过「设置 → 意见反馈」或 GitHub Issues 查询、更正、删除你的账号数据；
- 申请注销账号。注销后账号记录、额度与邀请关系将被删除或匿名化，且不可恢复；
- 拒绝首次启动时的隐私政策确认。拒绝后仍可使用不依赖控制端的本地功能，但版本更新、公告、资源库和账号额度不可用。

## 7. 未成年人

本应用面向在校学生。未满 14 周岁的用户应在监护人同意和指导下使用。若监护人发现未成年人未经同意使用，可联系开发者删除相关数据。

## 8. 政策更新

本政策更新时，App 会在首次启动或版本更新时展示最新文本。重大变更（例如新增收集字段、改变共享对象）会单独提示。
