04登录 / 授权状态页
正常路径不出现账号密码表单：App 先查本机 TGT 缓存，命中即静默换票，全程无密码、无验证码；只有 TGT 缺失且本机未保存密码时，才弹一次账号密码输入框。下方流程图给出真实 CAS 链路（TGT 复用 / ST 换发 / OSESSIONID 换取）与三会话分层，以及静默授权中、会话失效需重连、授权成功三种页面状态。
统一认证 → 云打印会话：TGT 复用链路
App 优先复用本机已缓存的 CAS TGT（学号归属、TTL 约 2 小时）：命中即静默换 ST，全程不弹输入框、不出现图形验证码；TGT 缺失时用本机 secure storage 里已保存的统一认证密码补登一次，同样不打扰用户。
1
检测网络模式
NetMode.direct（校内直连） / NetMode.webvpn（校外 WebVPN） / NetMode.offline
决定后续请求是否需要走 WebVPN 深澜网关改写地址；offline 时不发起任何请求。
2
查本机 TGT 缓存
key = CAS TGT · owner = 当前学号 · TTL ≈ 2h
先读本机缓存判断是否已有可用票据，再决定是否需要账号密码。
命中直接进入第 3 步换 ST —— 全程无密码、无验证码、静默完成。
未命中 / 失效用本机 secure storage 已保存的统一认证密码做一次 CAS 登录（验证码由 App 本地识别）→ 得 TGT → 写缓存 → 继续第 3 步。
无保存密码仅此时弹一次账号密码输入框；登录成功后同样写入 TGT 缓存，下次免输。
3
TGT → ST 换票
POST wxcas/lyuapServer/v1/tickets/<TGT> form{ service = https://kjyy.cwxu.edu.cn/authcenter/doAuth/<32hex> }
同一张 TGT 可换任意 service 的 ST（实测同一 TGT 连跑两次云打印 SSO 均可）；ST 一次性使用。
4
authcenter 校验 ST 并回跳
GET kjyy.cwxu.edu.cn/authcenter/doAuth/<id>?ticket=ST-… → 302 → /api/client/Auth/SSOLogin?targetPageUrl=…&uniToken=…
认证中心校验 ST 后 302 回云打印站点，并带上本次会话标识 sessionId。
5
换取云打印会话 cookie
GET /api/client/Auth/SSOLogin?uniToken=… → 302 → /api/client/Auth/UniEntry?SessionId=…&Func=BackUrl_… → GET UniEntry → 302 回目标页 → Set-Cookie: OSESSIONID
OSESSIONID 才是真正凭据，写入 WebView Cookie 容器并被 App 复用；未登录时接口返回 code 4。
6
之后所有扫描件请求携带 OSESSIONID
GET /api/client/Scan/Get · Download · POST /api/client/Scan/Del
列表、下载、删除三个动作共用同一会话；会话失效统一按「重新登录」处理，并可复用缓存 TGT 静默恢复。
账密复用用户不需要再次输入学号密码

统一认证密码来自本机 secure storage，App 内已加密保存；TGT 缓存命中时全程不弹输入框、不出现图形验证码，静默换票即可。

实测同一张 TGT 可连跑两次云打印 SSO，说明 TGT 是长生命周期身份票据，可反复换发新的 ST。

三会话分层
CAS TGT · 身份
代表「你是谁」，长 TTL（约 2 小时），本机缓存、可换任意 service 的 ST。
wxcas.cwxu.edu.cn/lyuapServer/v1/tickets/<TGT>
ST · 单次 service

OSESSIONID · 云打印站点会话
代表「云打印站点里的你是谁」，扫描件接口唯一凭据，失效返回 code 4。
