## R3 班级课表详情页：三段式重构

页面自上而下固定三段：

1. **班级基础信息** —— 学年学期 / 学院 / 专业 / 班级（只读 kv 卡）。
2. **班级课表** —— 一个班级可存在**多份**课表（多版本并存）。
   - 卡片**等宽**（两列网格，等宽等高），不按内容长短排布。
   - 卡片主行 = 版本号 + 状态标记（选中项标「预览中」）；**来源名不占卡面**，只在点开详情/tooltip 里看。
   - 卡片**小字只有三项**：`课程数 · 上传时间 · 上传者`（例：`28 门课 · 2 小时前 · 张同学`）。不再显示一致度、差异说明等次要信息。
3. **课程预览** —— **跟随第 2 段选中版本实时切换**（点哪个版本，下面预览立刻换成哪个版本），按星期分组列课程。

## R4 导入到我的课表：直接覆盖（带差异提示）

- **语义**：导入不再是「并存为新课表」，而是**直接覆盖**。本地对同一个班级只保留一份课表：
  - 本地已有该班课表 → **覆盖其课程**（表 id、名称保留，学期更新）。
  - 本地没有 → 新建一份该班课表并切换过去。
- **差异提示**：覆盖前弹差异摘要，三类计数 + 明细：
  - `新增 X 门`（本地没有的）
  - `变更 Y 门`（同名但节次 / 周次 / 教室不同）
  - `移除 Z 门`（本地有、新版没有）
- 差异为空时不弹差异区，直接确认。
- 确认按钮文案：`覆盖并导入`。取消 / 失败**不动原课表**，弹层不自动关闭。
- 导入成功后：写 `CourseStorage` → 切表 → 刷新今日课程与提醒（沿用现行 `course_table_home_page.dart` 的三条联动）。

## R6 提交新增「上传者名称」

- 上传向导 Step 3 新增**必填**字段「上传者名称」：
  - 长度 ≤ 16 字，服务端 `strip()` 后校验，超长报 400。
  - 默认带入用户昵称；昵称为空则要求手填。
  - 该名称作为课表的**作者展示名**，出现在：详情页版本卡小字、后台审核列表「提交者」列、审核详情。
- 隐私自检相应改写：「上传者名称请填昵称，不要填写真实姓名 / 学号 / 手机号」。
- 身份仍匿名化：服务端只存 `uploader_name`（用户自填昵称）+ 学号哈希前缀，**不存学号明文、不存真实姓名**。后台展示 = 昵称 + 哈希前缀。
