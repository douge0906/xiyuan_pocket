为什么可以放心用

没有服务器，数据只在你手机里

账号密码保存在系统安全存储（Android Keystore），App 在设备上直接与统一认证 / 教务 / 融合门户通信，不上传任何个人数据。

永久开源（MIT）

全部源码在 GitHub 公开，可自行编译、审阅、二次开发；构建产物也能从 Actions 直接下载。

轻、快、无后台

不依赖推送服务，通知全部在本地触发；内置内容快照，首次打开就有内容。

两个版本功能相近，差别在「有没有云端」：在线版多了推送、食堂速览与试卷库。 仓库地址：github.com/douge0906/xiyuan_pocket
