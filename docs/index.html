掌上锡院

无锡学院非官方校园助手 · 纯客户端 · 无服务器

Android arm64 · 开源版 v1.0.0 · MIT License

下载 Android 版 查看源码

下载的是开源版（15 MB，无服务器 · 直连学校系统 · 数据只留本机）

功能

课程表

教务系统一键导入或手动添加，支持单双周与自定义节次，可添加桌面小组件。

成绩 · 考试 · 教材

按学期查询成绩与绩点、本学期考试安排与考场、教材预订清单，本地缓存离线可看。

一卡通 · 电费余额

在服务页顶部直接查看校园卡余额与宿舍电费，不用再打开网页版。

教务处公告 · 校园资讯

内置内容快照，首次打开就有内容；之后联网刷新，未读的会标红点。

校历 · 校园地图

学年校历（周次与假期）与校园地图全部离线内置，地图可缩放拖动、点课程定位教室。

上课提醒

每节课前本地通知提醒，可设提前量；不依赖任何推送服务。

为什么可以放心用

没有服务器，数据只在你手机里

账号密码保存在系统安全存储（Android Keystore），App 直接与学校系统通信，不经过任何第三方服务器，也不上传任何个人数据。

永久开源（MIT）

全部源码公开在 GitHub，可自行编译、审阅、二次开发。构建产物也可以直接从 Actions 里下载。

非官方，请注意

本应用由个人开发者与 AI 辅助设计，非无锡学院官方产品。通过非官方客户端访问教务系统可能违反学校规定，请自行判断后使用。
